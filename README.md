# indexsvg

Index lightweight svg statistics from stdin samples.

**Site:** https://theworker02.github.io/indexsvg/

## Install / run

```bash
git clone https://github.com/theworker02/indexsvg.git
cd indexsvg
node src/cli.js
node --test
```
